# Struktura lekcji

## Uzgodniony rytm

1. Chcę osiągnąć taki efekt.
2. Pokaż mi, co zrobić na aparacie.
3. Krótka animacja lub czytelny widok Canona RP wskazuje element.
4. Prawdziwy przycisk, pokrętło lub ekran.
5. Prawdziwe menu, jeżeli jest potrzebne.
6. Krótkie wyjaśnienie: dlaczego to działa.
7. Przykład przed / po.
8. Ćwiczenie do wykonania.
9. Podsumowanie jednym zdaniem.

Nazwę fotograficzną wprowadzamy po zrozumieniu zjawiska. Film nie zastępuje czytelnych instrukcji. Nie każda lekcja musi otwierać menu.

## Wzór opisu do wykorzystania przy tworzeniu lekcji

| Pole | Co wpisujemy |
| --- | --- |
| ID, tytuł, poziom | Stabilny identyfikator i tytuł opisujący cel |
| Status | Szkic / do sprawdzenia na aparacie / zweryfikowana |
| Cel | Co Ania ma umieć zrobić po lekcji |
| Wymagania | Wcześniejsza wiedza, obiektyw, warunki i potrzebne przedmioty |
| Punkt startowy | Tryb aparatu i istotne ustawienia |
| Kroki | Działanie → co powinno pojawić się na ekranie lub zdjęciu |
| Materiały | Odwołania do aparatu, menu, animacji i zdjęć porównawczych |
| Wyjaśnienie | Krótkie uzasadnienie oraz termin, jeśli potrzebny |
| Ćwiczenie | Co sfotografować, co zmienić, co porównać |
| Kryterium efektu | Po czym poznać, że cel został osiągnięty |
| Pomoc | Najczęstszy problem i powiązana lekcja |
| Kontekst AI | Cel ćwiczenia i maksymalnie dwa priorytety informacji zwrotnej |
| Źródła i weryfikacja | Instrukcja, ekran, data, tryb i firmware |

Ten wzór porządkuje treść; nie narzuca jeszcze schematu bazy ani technologii aplikacji. Numer „Lekcja 6” z przykładu w rozmowie nie jest przypisany do konkretnej lekcji.

## Zaakceptowany wzorzec — 18.09.2026

Użytkownik zaakceptował formę [L1-01 — Robię swoje pierwsze zdjęcie](L1-01_ROBIE_SWOJE_PIERWSZE_ZDJECIE.md) jako wzorzec kolejnych lekcji (decyzja D-15).

Kolejne lekcje zachowują:

1. Bezpośredni zwrot do Ani, prosty język, cel i orientacyjny czas.
2. Krótkie przygotowanie i czytelny punkt startowy.
3. Numerowane kroki „zrób → sprawdź”: działanie i oczekiwany rezultat.
4. Krótkie wyjaśnienie po wykonaniu czynności.
5. Praktyczne ćwiczenie z aparatem.
6. Pomoc przy typowych trudnościach.
7. Proste kryteria ukończenia oraz jedno zdanie do zapamiętania.
8. Osobną kartę redakcyjną: źródła, materiały, stan weryfikacji i kontekst nauczyciela AI.

Liczbę kroków i czas dostosowujemy do tematu; sześć kroków pierwszej lekcji nie jest sztywnym wymaganiem. Zdjęcia, animacje i porównania dołączamy zgodnie z potrzebą lekcji i dostępnością sprawdzonych materiałów. Akceptacja formy nie zastępuje testu instrukcji na aparacie ani nie zatwierdza technologii lub interfejsu aplikacji.
