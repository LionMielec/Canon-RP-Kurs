# review/

Ten folder zawiera lekkie kopie materiałów (JPEG, dłuższy bok najwyżej 2000 px) przeznaczone wyłącznie do przeglądu przez Claude w czacie: podglądy i rendery materiałów lekcji oraz zdjęcia źródłowe aparatu i menu. Kopie nie zawierają lokalizacji GPS ani numerów seryjnych, a folder nie jest częścią aplikacji; pełne rendery i oryginalne zdjęcia pozostają lokalnie u właściciela, poza Git. Zasady opisuje decyzja D-053 w `docs/09_DECISIONS.md`.
