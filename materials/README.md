Dokładne źródła, daty, ograniczenia wydań i sumy kontrolne zapisano w [opisie instrukcji](canon-official/README.md). Wersja pliku instrukcji nie potwierdza firmware aparatu Ani. Nowsza polska instrukcja dla firmware 1.4.0 pozostaje do pozyskania; obecna kopia jest wydaniem początkowym.

PDF są zapisane lokalnie i ignorowane przez Git. Nie zostały wysłane na GitHub. Na innym komputerze trzeba je pobrać z zapisanych źródeł lub przenieść osobno. Rejestry Markdown mogą być wersjonowane z dokumentacją.

Po przyjęciu kolejnych plików dopisujemy ID, nazwę, autora, datę, warunki użycia, lokalizację, cel i status weryfikacji. Nie zapisujemy sekretów ani prywatnych danych EXIF w rejestrze.
